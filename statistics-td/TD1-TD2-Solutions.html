Statistics · TD1 & TD2 — ចម្លើយ និងការពន្យល់តាមជំហាន

I3–TD1 Descriptive Statistics · I3–TD2 Point Estimation and Confidence Intervals

ឯកសារនេះផ្តល់ចម្លើយ និងការពន្យល់ជាជំហានៗ សម្រាប់លំហាត់ទាំងអស់នៃ TD1 (1–9) និង TD2 (1–26)។ ពាក្យបច្ចេកទេសសំខាន់ៗរក្សាទុកជាភាសាអង់គ្លេសក្នុងវង់ក្រចក ដើម្បីងាយផ្ទៀងជាមួយមេរៀន។ លេខទាំងអស់ត្រូវបានគណនាឡើងវិញ ហើយត្រូវគ្នានឹង \(\sum x_i\), \(\sum x_i^2\) ដែលលំហាត់ផ្តល់ឲ្យ។

វិធានដែលប្រើក្នុងឯកសារនេះ៖
  • Percentile \(P_k\) (និង quartile)៖ តម្រៀបទិន្នន័យពីតូចទៅធំ រួចគណនា \(i = n\cdot\frac{k}{100}\)។ បើ \(i\) ជាចំនួនគត់ → យកមធ្យមនៃតម្លៃទី \(i\) និងទី \(i+1\)។ បើ \(i\) មិនមែនជាចំនួនគត់ → បង្គត់ឡើង ហើយយកតម្លៃនៅទីតាំងនោះ។ \(Q_1=P_{25}\), \(Q_2=\) median, \(Q_3=P_{75}\)។ (នេះគឺ quantile(..., type = 2) ក្នុង R។)
  • Outlier តាម IQR៖ \(IQR=Q_3-Q_1\); របង (fences) \(Q_1-1.5\,IQR\) និង \(Q_3+1.5\,IQR\)។ តម្លៃនៅក្រៅរបង = outlier។
  • Outlier តាម z-score៖ \(z=\frac{x-\bar x}{s}\); outlier បើ \(|z|>3\)។
  • វ៉ារ្យង់គំរូ (sample variance)៖ \(s^2=\frac{\sum x_i^2-\frac{(\sum x_i)^2}{n}}{n-1}\)។

I3–TD1 · Descriptive Statistics

Part A. Tutorial Problems

លំហាត់ 1. Descriptive ឬ Inferential?

គន្លឹះ៖ Descriptive = គ្រាន់តែរៀបរាប់ទិន្នន័យដែលបានវាស់ (មិនទាញសេចក្តីសន្និដ្ឋានហួសពីទិន្នន័យ)។ Inferential = ប្រើគំរូ (sample) ដើម្បីទាញសេចក្តីសន្និដ្ឋាន ប៉ាន់ស្មាន ឬទស្សន៍ទាយអំពីប្រជាជន (population) ទាំងមូល ឬអនាគត។

ចម្លើយហេតុផល
(a)Descriptiveជាមធ្យមភាគនៃទឹកភ្លៀងដែលបានកត់ត្រារួច (ខែ 1–6 ឆ្នាំ 2025)។
(b)Inferentialពីគំរូ 500 គ្រួសារ ប៉ាន់ស្មានទៅ “គ្រួសារទាំងអស់” នៅភ្នំពេញ។
(c)Descriptiveគ្រាន់តែរាប់ចំនួនខូចក្នុងគំរូ 200 គ្រាប់ (មិនបានទាញសេចក្តីសន្និដ្ឋានទៅផលិតកម្មទាំងមូល)។
(d)Inferentialជាការទស្សន៍ទាយអនាគត (ឆ្នាំ 2035)។
(e)Descriptiveសិស្ស 35 នាក់ គឺជាថ្នាក់ទាំងមូល; មធ្យមភាគ 14.2 រៀបរាប់ពួកគេផ្ទាល់។
(f)Inferentialពីអ្នកបើកបរ 1200 នាក់ ទាញសេចក្តីសន្និដ្ឋានទូទៅអំពីហានិភ័យសម្រាប់អ្នកបើកបរទាំងអស់។

លំហាត់ 2. ប្រភេទអថេរ និងកម្រិតរង្វាស់ (level of measurement)

គន្លឹះ៖ Nominal = ឈ្មោះ/ប្រភេទ គ្មានលំដាប់; Ordinal = មានលំដាប់ តែគម្លាតមិនមានន័យ; Interval = គម្លាតមានន័យ តែ 0 មិនមែន “គ្មាន” (មិនអាចនិយាយ “ពីរដង”); Ratio = មាន 0 ពិតប្រាកដ (0 = គ្មាន) អាចប្រៀបធៀបជាផលធៀប។

លំហាត់ 3. កម្ពស់សិស្ស 14 នាក់

  1. តម្រៀប៖ 155, 158, 160, 162, 163, 165, 165, 165, 168, 169, 170, 172, 175, 180 (\(n=14\))។
  2. Mean៖ \(\bar x=\frac{\sum x_i}{n}=\frac{2327}{14}=166.21\) cm។
  3. Mode៖ 165 លេចឡើង 3 ដង (ច្រើនជាងគេ) → mode \(=165\) cm។
  4. Median៖ \(n\) គូ → មធ្យមនៃតម្លៃទី 7 និងទី 8៖ \(\frac{165+165}{2}=165\) cm។
  5. Quartiles៖ \(Q_1\): \(14\times0.25=3.5\) → បង្គត់ឡើងជាទី 4 → \(Q_1=162\)។ \(Q_3\): \(14\times0.75=10.5\) → ទី 11 → \(Q_3=170\)។
    \(IQR=170-162=8\) cm។ (វិធី “median នៃពាក់កណ្តាលនីមួយៗ” ក៏ផ្តល់ 162 និង 170 ដូចគ្នា។)
  6. Midrange៖ \(\frac{\min+\max}{2}=\frac{155+180}{2}=167.5\) cm។
  7. Variance៖ \(s^2=\frac{\sum x_i^2-\frac{(\sum x_i)^2}{n}}{n-1}=\frac{387371-\frac{2327^2}{14}}{13}=\frac{387371-386780.64}{13}=\frac{590.36}{13}=45.41\) cm²។
  8. Standard deviation៖ \(s=\sqrt{45.41}=6.74\) cm។
\(\bar x=166.21\); mode \(=165\); median \(=165\); \(IQR=8\); midrange \(=167.5\); \(s^2=45.41\); \(s=6.74\)

លំហាត់ 4. ពិន្ទុណាមានទីតាំងធៀប (relative position) ល្អជាងគេ?

ប្រៀបធៀបដោយ z-score \(z=\frac{x-\bar x}{s}\) (ចំនួន standard deviation ខាងលើមធ្យមភាគ)៖

  1. Physics: \(z=\frac{72-65}{10}=0.70\)
  2. Mathematics: \(z=\frac{80-74}{6}=1.00\)
  3. Programming: \(z=\frac{15-12}{4}=0.75\)
Mathematics (\(z=1.00\) ធំជាងគេ) — ពិន្ទុ 80 ស្ថិតខាងលើមធ្យមភាគ 1 standard deviation

លំហាត់ 5. ពិនិត្យ outlier ដោយ IQR និង z-score

(a) 48, 52, 50, 55, 51, 49, 85 (\(\bar x=55.71\), \(s=13.11\))
  1. តម្រៀប៖ 48, 49, 50, 51, 52, 55, 85 (\(n=7\))។
  2. \(Q_1\): \(7\times0.25=1.75\) → ទី 2 → \(Q_1=49\)។ \(Q_3\): \(7\times0.75=5.25\) → ទី 6 → \(Q_3=55\)។ \(IQR=6\)។
  3. របង៖ \(49-1.5(6)=40\) និង \(55+1.5(6)=64\)។ 85 > 64 → 85 ជា outlier (IQR)។
  4. z-score នៃ 85៖ \(z=\frac{85-55.71}{13.11}=2.23\)។ \(|z|<3\) → មិនមែន outlier (z-score)។
(b) 12, 15, 9, 14, 30, 11, 13, 10, 16, 2 (\(\bar x=13.2\), \(s=7.10\))
  1. តម្រៀប៖ 2, 9, 10, 11, 12, 13, 14, 15, 16, 30 (\(n=10\))។
  2. \(Q_1\): \(10\times0.25=2.5\) → ទី 3 → \(Q_1=10\)។ \(Q_3\): \(7.5\) → ទី 8 → \(Q_3=15\)។ \(IQR=5\)។
  3. របង៖ \(10-7.5=2.5\) និង \(15+7.5=22.5\)។ 2 និង 30 ជា outliers (IQR)។
  4. z-score៖ \(z(30)=\frac{30-13.2}{7.10}=2.37\), \(z(2)=\frac{2-13.2}{7.10}=-1.58\)។ គ្មាន \(|z|>3\) → គ្មាន outlier (z-score)។

តើវិធីទាំងពីរផ្តល់លទ្ធផលដូចគ្នាទេ? ទេ — IQR រកឃើញ outlier តែ z-score មិនរកឃើញ

ពន្យល់៖ \(\bar x\) និង \(s\) ខ្លួនឯងត្រូវបាន outlier ទាញ (outlier ធ្វើឲ្យ \(s\) ធំ) ដូច្នេះ z-score របស់ outlier តូចជាងការពិត (masking)។ សម្រាប់គំរូតូច \(|z|\) មិនអាចលើស \(\frac{n-1}{\sqrt n}\) បានទេ៖ \(n=7\) → \(2.27\); \(n=10\) → \(2.85\)។ ដូច្នេះច្បាប់ \(|z|>3\) មិនអាចរកឃើញ outlier ណាមួយបានឡើយក្នុងករណីនេះ។ Quartiles មិនសូវរងឥទ្ធិពលពី outlier (resistant) ដូច្នេះវិធី IQR គួរទុកចិត្តជាងសម្រាប់គំរូតូច។

លំហាត់ 6. ប្រាក់ខែចាប់ផ្តើម (\(n=20\), តម្រៀបរួច)

(a)
  1. Median៖ \(n=20\) គូ → មធ្យមនៃទី 10 និងទី 11៖ \(\frac{540+550}{2}=545\)។
  2. \(Q_1\): \(20\times0.25=5\) (ចំនួនគត់) → មធ្យមនៃទី 5 និងទី 6៖ \(\frac{460+480}{2}=470\)។
  3. \(Q_3\): \(20\times0.75=15\) → មធ្យមនៃទី 15 និងទី 16៖ \(\frac{620+650}{2}=635\)។
median \(=\$545\), \(Q_1=\$470\), \(Q_3=\$635\)
(b)
  1. \(P_{26}\): \(20\times0.26=5.2\) → បង្គត់ឡើងជាទី 6 → \(480\)។
  2. \(P_{83}\): \(20\times0.83=16.6\) → ទី 17 → \(700\)។
\(P_{26}=\$480\), \(P_{83}=\$700\)
(c)
  1. \(IQR=635-470=165\); \(1.5\,IQR=247.5\)។
  2. របង៖ \(470-247.5=222.5\) និង \(635+247.5=882.5\)។
  3. មានតែ 1200 > 882.5។
$1200 ជា outlier
(d) Mean \(=\$585\) > median \(=\$545\)។ ប្រាក់ខែ $1200 (outlier) ទាញ mean ឡើងលើ (ទិន្នន័យ skewed ទៅស្តាំ)។ Median មិនរងឥទ្ធិពលពី outlier។ Median ($545) តំណាងប្រាក់ខែ “ធម្មតា” បានល្អជាង

លំហាត់ 7. Basic measures (ផ្ទៀងលំហាត់ 3)

h <- c(158, 165, 170, 162, 175, 168, 160, 165, 172, 180, 155, 165, 169, 163)
mean(h)                    # 166.2143
median(h)                  # 165
var(h)                     # 45.41209
sd(h)                      # 6.738849
min(h); max(h)             # 155  180
(min(h) + max(h)) / 2      # midrange = 167.5

# (b) mode
tab <- table(h); tab
names(tab)[tab == max(tab)]   # "165"  (appears 3 times)

# (c) quartiles
quantile(h, c(0.25, 0.75))            # 162.25  169.75   (default type = 7)
diff(quantile(h, c(0.25, 0.75)))      # IQR = 7.5
quantile(h, c(0.25, 0.75), type = 2)  # 162  170
IQR(h, type = 2)                      # 8

(c) type = 2 ផ្តល់ \(Q_1=162\), \(Q_3=170\), \(IQR=8\) ដូចការគណនាដោយដៃ Type 7 (default) ប្រើការ interpolate រវាងតម្លៃពីរ ដូច្នេះបាន 162.25 និង 169.75។

លំហាត់ 8. Percentiles និង outliers (ផ្ទៀងលំហាត់ 5 និង 6)

ចំណាំ៖ ប្រាក់ខែស្ថិតក្នុងលំហាត់ 6 (មិនមែន 7) ហើយទិន្នន័យពីរ “of Exercise 6” គឺទិន្នន័យ (a), (b) នៃលំហាត់ 5។

s <- c(380, 410, 420, 450, 460, 480, 500, 510, 520, 540,
       550, 560, 580, 600, 620, 650, 700, 750, 820, 1200)
quantile(s, c(0.25, 0.50, 0.75, 0.26, 0.83), type = 2)
#  25%  50%  75%  26%  83%
#  470  545  635  480  700

# (b)
outliers_iqr <- function(v) {
  q   <- quantile(v, c(0.25, 0.75), type = 2)
  iqr <- q[2] - q[1]
  v[v < q[1] - 1.5 * iqr | v > q[2] + 1.5 * iqr]
}
outliers_iqr(s)                                    # 1200
outliers_iqr(c(48, 52, 50, 55, 51, 49, 85))        # 85
outliers_iqr(c(12, 15, 9, 14, 30, 11, 13, 10, 16, 2))  # 30  2

# (c)
z <- scale(s)
round(z[s == 1200], 2)                             # 3.34

(c) \(\bar x=585\), \(s=184.29\) → \(z=\frac{1200-585}{184.29}=3.34\)។ \(|z|=3.34>3\) → $1200 ជា outlier តាមច្បាប់ \(|z|>3\) ផងដែរ

I3–TD2 · Point Estimation and Confidence Intervals for the Mean

Part A. Point Estimation — A.1 Estimators and their properties

លំហាត់ 1. Concepts (True/False)

ចម្លើយពន្យល់ / កែតម្រូវ
(a)Falseច្រាសគ្នា៖ estimator ជាអថេរចៃដន្យ (រូបមន្តនៃគំរូ ឧ. \(\bar X\)); estimate ជាលេខដែលគណនាពីទិន្នន័យជាក់ស្តែង (ឧ. \(\bar x=75.6\))។
(b)FalseUnbiased មានន័យថា \(E(\hat\theta)=\theta\) ជាមធ្យម (លើគំរូច្រើន) មិនមែនស្មើ \(\theta\) គ្រប់គំរូទេ។
(c)Trueរវាង estimators unbiased ពីរ មួយដែល variance តូចជាង គឺ efficient ជាង។
(d)True\(E(\hat\sigma^2)=\frac{n-1}{n}\sigma^2<\sigma^2\) → ប៉ាន់ស្មានទាបជាងការពិតជាមធ្យម។
(e)TrueConsistent៖ \(\hat\theta\) ខិតជិត \(\theta\) (តាមប្រូបាប) ពេល \(n\to\infty\)។
(f)True\(SE(\bar X)=\frac{\sigma}{\sqrt n}\) ថយចុះពេល \(n\) កើន។

លំហាត់ 2. Pull-off force (\(n=26\), \(\sum x_i=1966.0\), \(\sum x_i^2=148728.30\))

(a) ប្រើ sample mean \(\bar X\) ព្រោះវា unbiased (\(E(\bar X)=\mu\)), consistent និងមាន variance តូច (\(\sigma^2/n\))។ \[\bar x=\frac{1966.0}{26}=75.615\] \(\hat\mu=\bar x\approx75.62\) pounds
(b) តម្លៃដែលបំបែក 50% ខ្សោយ និង 50% ខ្លាំង = median។ តម្រៀប៖ 72.9, 73.8, 73.8, 73.9, 74.0, 74.1, 74.2, 74.6, 74.7, 74.9, 75.0, 75.1, 75.1, 75.3, 75.4, 75.5, 75.9, 76.2, 76.3, 76.8, 77.3, 77.6, 78.0, 78.1, 78.2, 79.3។ \(n=26\) → មធ្យមនៃទី 13 និងទី 14៖ \(\frac{75.1+75.3}{2}\)។ \(\tilde x=75.2\) pounds
(c) \[s^2=\frac{148728.30-\frac{1966^2}{26}}{25}=\frac{148728.30-148659.85}{25}=\frac{68.45}{25}=2.738,\qquad s=\sqrt{2.738}=1.655\] \(\hat\sigma^2=s^2\approx2.738\) pound², \(\hat\sigma=s\approx1.655\) pounds
(d) \(SE=\frac{s}{\sqrt n}=\frac{1.655}{\sqrt{26}}=0.325\)។ \(SE\approx0.32\) pound — ជាទូទៅ \(\bar x\) ខុសពី \(\mu\) ពិតប្រហែល 0.32 pound ប៉ុណ្ណោះ ដូច្នេះការប៉ាន់ស្មាន 75.62 មានភាពជាក់លាក់ខ្ពស់។
(e) មានតែ 72.9 ដែល < 73។ \(\hat p=\frac{1}{26}\)។ \(\hat p\approx0.038\) (3.8%)

លំហាត់ 3. Natural gas usage (\(n=10\))

(a) \(\sum x_i=1206\) → \(\bar x=\frac{1206}{10}\)។ \(\hat\mu=120.6\) therms
(b) \(\tau=N\mu\) ដូច្នេះប្រើ estimator \(\hat\tau=N\bar X\) (unbiased ព្រោះ \(E(N\bar X)=N\mu\))។ \(\hat\tau=10000\times120.6\)។ \(\hat\tau=1\,206\,000\) therms
(c) ផ្ទះដែលប្រើ ≥ 100៖ 103, 156, 118, 125, 147, 122, 109, 138 → 8 ផ្ទះ (89 និង 99 មិនរាប់)។ \(\hat p=\frac{8}{10}=0.8\)
(d) ប្រើ sample median។ តម្រៀប៖ 89, 99, 103, 109, 118, 122, 125, 138, 147, 156 → \(\frac{118+122}{2}\)។ \(\tilde x=120\) therms

លំហាត់ 4. Asphalt density៖ ហេតុអ្វីចែកនឹង \(n-1\)?

(a)
  1. \(\sum x_i=18.46\) → \(\bar x=\frac{18.46}{8}=2.3075\) g/cm³។
  2. \(\sum x_i^2=42.602\) → \(\sum(x_i-\bar x)^2=42.602-\frac{18.46^2}{8}=42.602-42.59645=0.00555\)។
  3. \(S^2=\frac{0.00555}{7}=0.000793\)។
\(\hat\mu=2.3075\) g/cm³, \(S^2\approx7.93\times10^{-4}\) (\(S\approx0.028\))
(b) \(\hat\sigma_1^2=\frac{0.00555}{8}=0.000694\) < \(S^2\)។ ដោយ \(E(\hat\sigma_1^2)=\frac{n-1}{n}\sigma^2\)៖ \[\text{bias}(\hat\sigma_1^2)=E(\hat\sigma_1^2)-\sigma^2=-\frac{\sigma^2}{n}=-\frac{\sigma^2}{8}\] \(\hat\sigma_1^2\approx6.94\times10^{-4}\) តូចជាង; bias \(=-\sigma^2/8\)
(c) គម្លាតត្រូវបានវាស់ពី \(\bar x\) ដែលគណនាចេញពីទិន្នន័យដដែល ដូច្នេះ \(\bar x\) “ស្ថិតនៅកណ្តាល” ទិន្នន័យជានិច្ច ហើយ \(\sum(x_i-\bar x)^2\le\sum(x_i-\mu)^2\)។ ការចែកនឹង \(n\) ធ្វើឲ្យ variance តូចជាងការពិត។ ម្យ៉ាងទៀត គម្លាតទាំង \(n\) មានផលបូកស្មើ 0 ដូច្នេះមានតែ \(n-1\) ប៉ុណ្ណោះដែលឯករាជ្យ (degrees of freedom)។ ចែកនឹង \(n-1\) ធ្វើឲ្យ \(E(S^2)=\sigma^2\) (unbiased)។
(d) ដង់ស៊ីតេមធ្យមប្រហែល 2.31 g/cm³ ហើយការប្រែប្រួលតូចណាស់ (\(S\approx0.028\) ≈ 1.2% នៃមធ្យមភាគ) → ការបង្ហាប់ asphalt មានភាពស្មើគ្នាល្អ។ បើប្រើ \(\hat\sigma_1^2\) យើងនឹងប៉ាន់ស្មានការប្រែប្រួលទាបពេក ហើយវាយតម្លៃគុណភាពល្អហួសការពិត ដូច្នេះត្រូវប្រើ \(S^2\) សម្រាប់ quality assurance។

លំហាត់ 5. ប្រៀបធៀប estimators បួន

\(\hat\mu_1=X_1\), \(\hat\mu_2=\frac{X_1+2X_2+X_3}{4}\), \(\hat\mu_3=\bar X=\frac{X_1+X_2+X_3}{3}\), \(\hat\mu_4=\frac{X_1+X_2+X_3}{4}\)។

(a) ប្រើ \(E(aX_1+bX_2+cX_3)=(a+b+c)\mu\)៖
  1. \(E(\hat\mu_1)=\mu\) → unbiased។
  2. \(E(\hat\mu_2)=\frac{1+2+1}{4}\mu=\mu\) → unbiased។
  3. \(E(\hat\mu_3)=\frac{3}{3}\mu=\mu\) → unbiased។
  4. \(E(\hat\mu_4)=\frac34\mu\) → biased; bias \(=\frac34\mu-\mu=-\frac{\mu}{4}\)។
\(\hat\mu_1,\hat\mu_2,\hat\mu_3\) unbiased; \(\hat\mu_4\) biased ដោយ bias \(-\mu/4\)
(b) \(\mathrm{Var}(aX_1+bX_2+cX_3)=(a^2+b^2+c^2)\sigma^2\)៖ \[\mathrm{Var}(\hat\mu_1)=\sigma^2,\quad \mathrm{Var}(\hat\mu_2)=\tfrac{1+4+1}{16}\sigma^2=\tfrac{3}{8}\sigma^2,\quad \mathrm{Var}(\hat\mu_3)=\tfrac{3}{9}\sigma^2=\tfrac{\sigma^2}{3},\quad \mathrm{Var}(\hat\mu_4)=\tfrac{3}{16}\sigma^2\]
(c) ក្នុងចំណោម unbiased៖ \(\frac{\sigma^2}{3}<\frac{3\sigma^2}{8}<\sigma^2\)។ \(\hat\mu_3=\bar X\) efficient ជាងគេ
(d) \(\mathrm{MSE}=\mathrm{Var}+\text{bias}^2\)៖ \[\mathrm{MSE}(\hat\mu_3)=\frac{\sigma^2}{3},\qquad \mathrm{MSE}(\hat\mu_4)=\frac{3\sigma^2}{16}+\frac{\mu^2}{16}\] \(\hat\mu_4\) ល្អជាងពេល \(\frac{3\sigma^2+\mu^2}{16}<\frac{\sigma^2}{3}\) ⇔ \(\mu^2<\left(\frac{16}{3}-3\right)\sigma^2=\frac73\sigma^2\)។ \(\mu^2/\sigma^2<7/3\approx2.33\)

លំហាត់ 6. Sample proportion

(a) \(E(\hat p)=E\!\left(\frac{X}{n}\right)=\frac{E(X)}{n}=\frac{np}{n}=p\) → \(\hat p\) unbiased។
(b) \(\mathrm{Var}(\hat p)=\frac{\mathrm{Var}(X)}{n^2}=\frac{np(1-p)}{n^2}=\frac{p(1-p)}{n}\) → \(SE(\hat p)=\sqrt{\frac{p(1-p)}{n}}\)។ ក្នុងការអនុវត្ត \(p\) មិនស្គាល់ ដូច្នេះជំនួសដោយ \(\hat p\)៖ \(\widehat{SE}=\sqrt{\frac{\hat p(1-\hat p)}{n}}\)។
(c) \(\hat p\) unbiased ហើយ \(\mathrm{Var}(\hat p)=\frac{p(1-p)}{n}\to0\) ពេល \(n\to\infty\) → \(\hat p\) consistent

លំហាត់ 7. Network delay (\(n=12\))

(a) \(\sum x_i=236\), \(\sum x_i^2=4658\)។ \(\bar x=\frac{236}{12}=19.667\) ms; \(s^2=\frac{4658-\frac{236^2}{12}}{11}=\frac{4658-4641.33}{11}=\frac{16.67}{11}=1.515\) (\(s=1.231\))។ \(\bar x\approx19.67\) ms, \(s^2\approx1.52\) ms²
(b) \(E(A)=\mu\), \(E(B)=\mu\) → ទាំងពីរ unbiased។ \(\mathrm{Var}(A)=\frac{\sigma^2}{5}\), \(\mathrm{Var}(B)=\frac{\sigma^2}{12}\)។ B efficient ជាង (variance តូចជាង 2.4 ដង) ព្រោះប្រើទិន្នន័យទាំងអស់។
(c) \(SE(B)=\frac{s}{\sqrt{12}}=\frac{1.231}{3.464}=0.355\) ms។ \(SE\approx0.36\) ms — latency មធ្យមត្រូវបានប៉ាន់ស្មានបានជាក់លាក់ (ខុសប្រហែល ±0.36 ms) ហើយ packets មានពេលពន្យារស្ថិរភាព (18–22 ms) → ការបញ្ជូនទិន្នន័យអាចទុកចិត្តបាន។

លំហាត់ 8. ★ ផ្ទៃដីការ៉េ

(a) ដោយ \(E(Y^2)=\mathrm{Var}(Y)+[E(Y)]^2\) ជាមួយ \(Y=\bar X\)៖ \[E(\bar X^2)=\mathrm{Var}(\bar X)+[E(\bar X)]^2=\frac{\sigma^2}{n}+\mu^2\ne\mu^2\] ដូច្នេះ \(\bar X^2\) biased (bias \(=\sigma^2/n>0\), ប៉ាន់ស្មានធំជាងការពិត)។
(b) \(E(\bar X^2-kS^2)=\frac{\sigma^2}{n}+\mu^2-k\sigma^2\)។ ចង់បាន \(=\mu^2\) ⇔ \(\frac{\sigma^2}{n}-k\sigma^2=0\)។ \(k=\frac1n\)

A.2 Method of Moments (MOM) and Maximum Likelihood (MLE)

លំហាត់ 9. Waiting times (MOM)

(a)
  1. Exponential(\(\lambda\))៖ \(E(X)=\frac1\lambda\)។
  2. MOM៖ យក moment នៃគំរូ = moment នៃប្រជាជន៖ \(\bar X=\frac{1}{\lambda}\) → \(\hat\lambda=\frac{1}{\bar X}\)។
  3. \(\bar x=\frac{3.5+8.1+0.9+4.4+0.5}{5}=\frac{17.4}{5}=3.48\) នាទី → \(\hat\lambda=\frac{1}{3.48}=0.287\)។
\(\hat\lambda\approx0.287\) ក្នុងមួយនាទី — ប្រហែល 0.29 អតិថិជនត្រូវបានបម្រើក្នុងមួយនាទី ឬរង់ចាំជាមធ្យម 3.48 នាទី។
(b) \(E(\bar X)=E(X)=\theta\) → unbiased។ \(\mathrm{Var}(\bar X)=\frac{\mathrm{Var}(X)}{n}=\frac{\theta^2}{n}\)។
(c) unbiased ហើយ \(\mathrm{Var}(\bar X)=\frac{\theta^2}{n}\to0\) → consistent។ \(\hat\theta=\bar x=3.48\) នាទី

លំហាត់ 10. Weld strength (MOM ពីរ parameters)

(a)
  1. Moment ទី 1៖ \(\bar X=\mu\) → \(\hat\mu=\frac{3844}{10}=384.4\) psi។
  2. Moment ទី 2៖ \(\frac1n\sum X_i^2=\sigma^2+\mu^2\) → \(\hat\sigma^2=\frac1n\sum x_i^2-\bar x^2=\frac{1481190}{10}-384.4^2=148119-147763.36=355.64\)។
\(\hat\mu=384.4\) psi, \(\hat\sigma^2=355.64\) (\(\hat\sigma\approx18.86\))
(b) MOM estimator ចែកនឹង \(n\) → biased (\(E=\frac{n-1}{n}\sigma^2\))។ \(s^2=\frac{n}{n-1}\hat\sigma^2=\frac{10}{9}(355.64)\)។ \(s^2\approx395.16\) (\(s\approx19.88\))
(c) \(\hat x_{0.95}=\hat\mu+1.645\,\hat\sigma=384.4+1.645(18.86)\)។ ≈ 415.4 psi (បើប្រើ \(s\)៖ ≈ 417.1 psi)

លំហាត់ 11. Flaws in tape (MLE, Poisson)

(a)
  1. \(L(\lambda)=\prod\frac{e^{-\lambda}\lambda^{x_i}}{x_i!}=\frac{e^{-n\lambda}\lambda^{\sum x_i}}{\prod x_i!}\)។
  2. \(\ell(\lambda)=-n\lambda+\left(\sum x_i\right)\ln\lambda-\sum\ln(x_i!)\)។
  3. \(\ell'(\lambda)=-n+\frac{\sum x_i}{\lambda}=0\) → \(\hat\lambda=\frac{\sum x_i}{n}=\bar X\)។
  4. \(\ell''(\lambda)=-\frac{\sum x_i}{\lambda^2}<0\) → ជាអតិបរមា។
(b) \(E(\bar X)=\lambda\) → unbiased។ MOM៖ \(E(X)=\lambda\) → \(\hat\lambda_{MOM}=\bar X\) (ដូចគ្នានឹង MLE)។
(c) \(\sum x_i=0(5)+1(7)+2(12)+3(9)+4(5)+5(1)+6(1)=0+7+24+27+20+5+6=89\); \(n=40\)។ \(\hat\lambda=\frac{89}{40}=2.225\) ស្នាមខូចក្នុង 100 feet

លំហាត់ 12. False positives (MLE, proportion)

(a)
  1. \(\ell(p)=\ln\binom nx+x\ln p+(n-x)\ln(1-p)\)។
  2. \(\ell'(p)=\frac xp-\frac{n-x}{1-p}=0\) → \(x(1-p)=(n-x)p\) → \(\hat p=\frac xn\)។ (\(\ell''<0\) → អតិបរមា)
  3. \(n=20\), \(x=3\) → \(\hat p=\frac{3}{20}\)។
\(\hat p=0.15\)
(b) បាទ/ចាស៖ ដូចលំហាត់ 6(a) \(E(X/n)=p\) → unbiased
(c) \((1-\hat p)^5=0.85^5\)។ ≈ 0.444 (ប្រហែល 44%)

លំហាត់ 13. API response time (MLE, Exponential)

(a) \(L(\lambda)=\prod\lambda e^{-\lambda x_i}=\lambda^n e^{-\lambda\sum x_i}\); \(\ell(\lambda)=n\ln\lambda-\lambda\sum x_i\)។
(b) \(\ell'(\lambda)=\frac n\lambda-\sum x_i=0\) → \(\hat\lambda_{MLE}=\frac{n}{\sum x_i}=\frac{1}{\bar X}\)។ \(\ell''(\lambda)=-\frac{n}{\lambda^2}<0\) → អតិបរមា។
(c) \(\sum x_i=1706\) → \(\bar x=213.25\) ms → \(\hat\lambda=\frac{1}{213.25}\)។ \(\hat\lambda\approx0.00469\) requests/ms (≈ 4.7 requests/s); response time មធ្យម \(=213.25\) ms
(d) MOM៖ \(E(X)=\frac1\lambda\) → \(\hat\lambda=\frac1{\bar X}\)។ ដូចគ្នា (0.00469)
(e) មិនសមរម្យ — Exponential មាន SD = mean (≈ 213 ms) ហើយតម្លៃភាគច្រើននៅជិត 0 (mode = 0)។ តែទិន្នន័យទាំងអស់នៅចន្លោះ 208–219 ms (\(s\approx3.7\) ms) ដែលប្រែប្រួលតិចណាស់។ Normal distribution (ឬ distribution ដែលរំកិល) សមជាង។

Part B. Confidence Intervals for the Mean — B.1 σ known (z-interval)

រូបមន្ត៖ \(\bar x\pm z_{\alpha/2}\frac{\sigma}{\sqrt n}\) (σ ស្គាល់) និង \(\bar x\pm t_{\alpha/2,\,n-1}\frac{s}{\sqrt n}\) (σ មិនស្គាល់)។ ទំហំគំរូ៖ \(n=\left(\frac{z_{\alpha/2}\,\sigma}{E}\right)^2\) រួចបង្គត់ឡើង។

លំហាត់ 14. Conceptual understanding

(a) យើងជឿជាក់ 99% លើ វិធីសាស្ត្រ៖ បើយកគំរូច្រើនដង ហើយសង់ interval តាមរបៀបនេះ ប្រហែល 99% នៃ intervals នឹងមាន \(\mu\) ពិត។ \(\mu\) ជាចំនួនថេរ មិនមែនអថេរចៃដន្យទេ។
(b) 99% ធំទូលាយជាង ព្រោះ critical value ធំជាង (2.576 ធៀបនឹង 1.645)៖ ដើម្បីជឿជាក់ច្រើនជាង ត្រូវបើក interval ឲ្យធំ។
(c) ប្រើ z ពេល σ ស្គាល់ (ឬ \(n\) ធំ ឧ. \(n\ge30\) ប្រើ \(s\) ជំនួសបានប្រហាក់ប្រហែល)។ ប្រើ t (df \(=n-1\)) ពេល σ មិនស្គាល់ ប្រើ \(s\) ហើយ population ប្រហែល normal (ជាពិសេសពេល \(n\) តូច)។
(d) \(E=z\frac{\sigma}{\sqrt n}\)៖ \(n\) កាន់តែធំ → interval កាន់តែតូច។ បើ \(n\) គុណនឹង 4 → \(\sqrt n\) គុណនឹង 2 → margin of error ថយចុះពាក់កណ្តាល
(e) ការនិយាយនោះមិនត្រឹមត្រូវ៖ ក្រោយពេលគណនា interval [52.3, 55.7] រួច វាមាន \(\mu\) ឬអត់មាន (ប្រូបាប 1 ឬ 0)។ 95% សំដៅលើវិធីសាស្ត្រ (95% នៃ intervals ដែលសង់តាមរបៀបនេះមាន \(\mu\)) មិនមែនលើ interval មួយនេះទេ។

លំហាត់ 26. Simulation: មើលលក្ខណៈឲ្យឃើញផ្ទាល់

set.seed(2026)
# (a) bias of the variance
S2 <- replicate(10000, var(rnorm(5, mean = 50, sd = 10)))
mean(S2)            # ≈ 100  (S^2, divisor n-1)
mean(S2 * 4 / 5)    # ≈ 80   (sigma1^2, divisor n)

# (b), (c) coverage and width of the 95% t-interval
ci_sim <- function(n, B = 1000) {
  res <- replicate(B, {
    ci <- t.test(rnorm(n, mean = 50, sd = 10), conf.level = 0.95)$conf.int
    c(cover = ci[1] <= 50 & 50 <= ci[2], width = ci[2] - ci[1])
  })
  rowMeans(res)
}
ci_sim(25)     # cover ≈ 0.95, width ≈ 8.2
ci_sim(100)    # cover ≈ 0.95, width ≈ 4.0
(a) មធ្យមនៃ \(S^2\) ≈ 100 = \(\sigma^2\) (unbiased)។ មធ្យមនៃ \(\hat\sigma_1^2\) ≈ 80 = \(\frac{4}{5}\sigma^2\) → ប៉ាន់ស្មានទាប (bias \(=-\sigma^2/n=-20\))។ ត្រូវនឹងទ្រឹស្តីក្នុងលំហាត់ 4។
(b) សមាមាត្រ intervals ដែលមាន \(\mu=50\) ≈ 0.95 (ការក្លែងធ្វើរបស់យើងបាន 0.948)។ ជិត 0.95 — នេះជាអត្ថន័យនៃ “95% confidence”
(c) \(n=100\)៖ coverage នៅតែ ≈ 0.95 (មិនប្រែប្រួល) តែទទឹងមធ្យមថយពីប្រហែល 8.2 ទៅ 4.0 (ពាក់កណ្តាល) ព្រោះទទឹង \(\propto1/\sqrt n\) ហើយ \(\sqrt{100/25}=2\)។ (លេខពិតប្រាកដអាស្រ័យលើ seed។)
