Key ideaDescriptive vs inferential · ពិពណ៌នា និង សន្និដ្ឋាន

Exercise 3. Heights of 14 students លំហាត់ 3. កម្ពស់សិស្ស 14 នាក់

F1Sample mean · មធ្យមភាគគំរូ
\(\displaystyle \bar x=\frac{\sum x_i}{n}\)

Symbols: \(x_i\) = each value, \(\sum x_i\) = sum of all values, \(n\) = number of values. Use: the “centre of gravity” of the data; sensitive to outliers.

និមិត្តសញ្ញា៖ \(x_i\) = តម្លៃនីមួយៗ, \(\sum x_i\) = ផលបូកតម្លៃទាំងអស់, \(n\) = ចំនួនតម្លៃ។ ប្រើ៖ ចំណុចកណ្តាលនៃទិន្នន័យ; រងឥទ្ធិពលខ្លាំងពី outlier។

F2Median and mode · មេដ្យាន និង ម៉ូត
\(n\) odd: median \(=x_{\left(\frac{n+1}{2}\right)}\)   ·   \(n\) even: median \(=\dfrac{x_{(n/2)}+x_{(n/2+1)}}{2}\)

Symbols: \(x_{(k)}\) = the \(k\)-th value after sorting from smallest to largest. The mode is the value that occurs most often. Use: the median is the middle value; it is resistant to outliers.

និមិត្តសញ្ញា៖ \(x_{(k)}\) = តម្លៃទី \(k\) ក្រោយតម្រៀបពីតូចទៅធំ។ ម៉ូត = តម្លៃដែលលេចឡើងញឹកញាប់ជាងគេ។ ប្រើ៖ មេដ្យានជាតម្លៃកណ្តាល មិនសូវរងឥទ្ធិពលពី outlier។

F3Percentiles and quartiles · ភាគរយទី និង ក្វាទីល
\(\displaystyle i=n\cdot\frac{k}{100}\)  →  \(i\) integer: \(P_k=\dfrac{x_{(i)}+x_{(i+1)}}{2}\);   \(i\) not integer: \(P_k=x_{(\lceil i\rceil)}\)

Symbols: \(P_k\) = \(k\)-th percentile (about \(k\%\) of the data lie below it); \(\lceil i\rceil\) = round \(i\) up. \(Q_1=P_{25}\), \(Q_2=\) median, \(Q_3=P_{75}\). This is R's quantile(..., type = 2).

និមិត្តសញ្ញា៖ \(P_k\) = ភាគរយទី \(k\) (ប្រហែល \(k\%\) នៃទិន្នន័យនៅក្រោមវា); \(\lceil i\rceil\) = បង្គត់ឡើង។ \(Q_1=P_{25}\), \(Q_2=\) មេដ្យាន, \(Q_3=P_{75}\)។ ដូច type = 2 ក្នុង R។

F4Range, midrange, interquartile range · វិសាលភាព ចំណុចកណ្តាលវិសាលភាព និង IQR
\(R=\max-\min,\qquad \text{midrange}=\dfrac{\min+\max}{2},\qquad IQR=Q_3-Q_1\)

Use: the IQR is the spread of the middle 50% of the data (resistant to outliers).

ប្រើ៖ IQR ជាវិសាលភាពនៃ 50% កណ្តាលនៃទិន្នន័យ (មិនសូវរងឥទ្ធិពលពី outlier)។

F5Sample variance and standard deviation · វ៉ារ្យង់ និងគម្លាតស្តង់ដារគំរូ
\(\displaystyle s^2=\frac{\sum(x_i-\bar x)^2}{n-1}=\frac{\sum x_i^2-\frac{(\sum x_i)^2}{n}}{n-1},\qquad s=\sqrt{s^2}\)

Symbols: \(\sum x_i^2\) = sum of the squares, \((\sum x_i)^2\) = square of the sum (not the same!). Use: average squared distance from the mean. The second form (shortcut) is easiest when \(\sum x_i\) and \(\sum x_i^2\) are given. Divide by \(n-1\) for a sample.

និមិត្តសញ្ញា៖ \(\sum x_i^2\) = ផលបូកការេ, \((\sum x_i)^2\) = ការេនៃផលបូក (មិនដូចគ្នា!)។ ប្រើ៖ មធ្យមនៃការេគម្លាតពីមធ្យមភាគ។ រូបមន្តទីពីរ (shortcut) ងាយប្រើពេលគេឲ្យ \(\sum x_i\) និង \(\sum x_i^2\)។ សម្រាប់គំរូ ចែកនឹង \(n-1\)។

  1. Sort the data (\(n=14\)): 155, 158, 160, 162, 163, 165, 165, 165, 168, 169, 170, 172, 175, 180.តម្រៀបទិន្នន័យពីតូចទៅធំ។
  2. Mean (F1): \(\bar x=\frac{2327}{14}=166.21\) cm.មធ្យមភាគ៖ ចែកផលបូក 2327 នឹង 14 → 166.21 cm។
  3. Mode (F2): 165 occurs 3 times, more than any other value → mode \(=165\) cm.ម៉ូត៖ 165 លេចឡើង 3 ដង (ច្រើនជាងគេ) → 165 cm។
  4. Median (F2): \(n=14\) is even → average of the 7th and 8th values: \(\frac{165+165}{2}=165\) cm.មេដ្យាន៖ \(n\) គូ → មធ្យមនៃតម្លៃទី 7 និងទី 8 → 165 cm។
  5. Quartiles (F3): \(Q_1\): \(14\times0.25=3.5\) → round up to 4 → \(Q_1=162\). \(Q_3\): \(14\times0.75=10.5\) → 11th value → \(Q_3=170\). (F4) \(IQR=170-162=8\) cm.ក្វាទីល៖ 3.5 បង្គត់ឡើងជាទី 4 → \(Q_1=162\); 10.5 → ទី 11 → \(Q_3=170\); \(IQR=8\) cm។ (វិធី “median នៃពាក់កណ្តាលនីមួយៗ” ក៏បាន 162 និង 170 ដូចគ្នា។)
  6. Midrange (F4): \(\frac{155+180}{2}=167.5\) cm.ចំណុចកណ្តាលវិសាលភាព៖ មធ្យមនៃតម្លៃតូចបំផុត និងធំបំផុត → 167.5 cm។
  7. Variance (F5, shortcut):\(s^2=\dfrac{387371-\frac{2327^2}{14}}{13}=\dfrac{387371-386780.64}{13}=\dfrac{590.36}{13}=45.41\ \text{cm}^2\)វ៉ារ្យង់៖ ប្រើរូបមន្ត shortcut ជាមួយ \(\sum x_i=2327\), \(\sum x_i^2=387371\) → 45.41 cm²។
  8. Standard deviation: \(s=\sqrt{45.41}=6.74\) cm.គម្លាតស្តង់ដារ៖ ឫសការេនៃវ៉ារ្យង់ → 6.74 cm។
Answer / ចម្លើយ\(\bar x=166.21\) · mode \(=165\) · median \(=165\) · \(IQR=8\) · midrange \(=167.5\) · \(s^2=45.41\) · \(s=6.74\) (cm)

Exercise 4. Exam grades: best relative position លំហាត់ 4. ពិន្ទុណាមានទីតាំងធៀបល្អជាងគេ

F6z-score (standard score) · ពិន្ទុស្តង់ដារ
\(\displaystyle z=\frac{x-\bar x}{s}\)

Meaning: how many standard deviations \(x\) lies above (\(z>0\)) or below (\(z<0\)) the mean. Use: compare values from different scales; detect outliers (\(|z|>3\)).

អត្ថន័យ៖ \(x\) នៅខាងលើ (\(z>0\)) ឬខាងក្រោម (\(z<0\)) មធ្យមភាគប៉ុន្មានដងនៃគម្លាតស្តង់ដារ។ ប្រើ៖ ប្រៀបធៀបតម្លៃដែលមានខ្នាតខុសគ្នា; រក outlier (\(|z|>3\))។

  1. Physics: \(z=\frac{72-65}{10}=0.70\); Mathematics: \(z=\frac{80-74}{6}=1.00\); Programming: \(z=\frac{15-12}{4}=0.75\).គណនា z-score សម្រាប់មុខវិជ្ជានីមួយៗ។
  2. The largest \(z\) is the best relative position.z ធំជាងគេ = ទីតាំងធៀបល្អជាងគេ។
Answer / ចម្លើយMathematics (\(z=1.00\)): the grade 80 is one standard deviation above the mean.គណិតវិទ្យា (\(z=1.00\))៖ ពិន្ទុ 80 ខ្ពស់ជាងមធ្យមភាគ 1 គម្លាតស្តង់ដារ។

Exercise 5. Outliers: IQR method and z-score method លំហាត់ 5. រក outlier ដោយ IQR និង z-score

F7Outlier rules · ច្បាប់រក outlier
IQR fences: \(\;Q_1-1.5\,IQR\;\) and \(\;Q_3+1.5\,IQR\;\)   ·   z-score rule: \(|z|>3\)

Use: a value outside the fences (or with \(|z|>3\)) is an outlier. The IQR rule uses quartiles, so it is resistant; the z rule uses \(\bar x\) and \(s\), which the outlier itself pulls.

ប្រើ៖ តម្លៃនៅក្រៅរបង (ឬ \(|z|>3\)) ជា outlier។ ច្បាប់ IQR ប្រើក្វាទីល ដូច្នេះមិនសូវរងឥទ្ធិពល; ច្បាប់ z ប្រើ \(\bar x\) និង \(s\) ដែល outlier ខ្លួនឯងទាញ។

(a) 48, 52, 50, 55, 51, 49, 85  (\(\bar x=55.71\), \(s=13.11\))
  1. Sorted (\(n=7\)): 48, 49, 50, 51, 52, 55, 85.តម្រៀប។
  2. (F3) \(7\times0.25=1.75\) → 2nd → \(Q_1=49\); \(7\times0.75=5.25\) → 6th → \(Q_3=55\); \(IQR=6\).\(Q_1=49\), \(Q_3=55\), \(IQR=6\)។
  3. (F7) Fences: \(49-9=40\) and \(55+9=64\). Since \(85>64\), 85 is an outlier (IQR).របង 40 និង 64; 85 > 64 → 85 ជា outlier តាម IQR។
  4. (F6) \(z(85)=\frac{85-55.71}{13.11}=2.23<3\) → not an outlier (z).\(z=2.23<3\) → មិនមែន outlier តាម z-score។
(b) 12, 15, 9, 14, 30, 11, 13, 10, 16, 2  (\(\bar x=13.2\), \(s=7.10\))
  1. Sorted (\(n=10\)): 2, 9, 10, 11, 12, 13, 14, 15, 16, 30.តម្រៀប។
  2. (F3) \(10\times0.25=2.5\) → 3rd → \(Q_1=10\); \(7.5\) → 8th → \(Q_3=15\); \(IQR=5\).\(Q_1=10\), \(Q_3=15\), \(IQR=5\)។

A.2 Method of Moments and Maximum Likelihood · វិធី moment និង likelihood អតិបរមា

F14Method of moments (MOM) · វិធី moment
Set \(E(X)=\bar X\) (and, for two parameters, \(E(X^2)=\frac1n\sum X_i^2\)), then solve for the parameters.

Idea: population moments are replaced by the matching sample moments. One equation per unknown parameter.

គំនិត៖ ជំនួស moment នៃប្រជាជនដោយ moment នៃគំរូ។ សមីការមួយសម្រាប់ parameter មិនស្គាល់នីមួយៗ។

F15Maximum likelihood (MLE): 4 steps · likelihood អតិបរមា៖ 4 ជំហាន
\(L(\theta)=\prod_{i=1}^n f(x_i;\theta)\ \to\ \ell(\theta)=\ln L(\theta)\ \to\ \ell'(\theta)=0\ \to\ \ell''(\hat\theta)<0\)

Meaning: choose the parameter that makes the observed data most probable. Taking \(\ln\) turns the product into a sum, which is easier to differentiate. The second-derivative check confirms a maximum.

អត្ថន័យ៖ ជ្រើស parameter ដែលធ្វើឲ្យទិន្នន័យដែលបានសង្កេតមានប្រូបាបខ្ពស់បំផុត។ \(\ln\) ប្តូរផលគុណជាផលបូក ងាយធ្វើដេរីវេ។ ដេរីវេទីពីរអវិជ្ជមាន → អតិបរមា។

Distribution\(f(x)\)\(E(X)\)\(\mathrm{Var}(X)\)
Exponential(\(\lambda\))\(\lambda e^{-\lambda x},\ x\ge0\)\(1/\lambda\)\(1/\lambda^2\)
Poisson(\(\lambda\))\(e^{-\lambda}\lambda^x/x!,\ x=0,1,\ldots\)\(\lambda\)\(\lambda\)
Binomial(\(n,p\))\(\binom nx p^x(1-p)^{n-x}\)\(np\)\(np(1-p)\)
Normal(\(\mu,\sigma^2\))bell curve\(\mu\)\(\sigma^2\)

Exponential: waiting times (rate \(\lambda\)); Poisson: counts of events; Binomial: number of successes in \(n\) trials.

Exponential៖ ពេលរង់ចាំ; Poisson៖ ចំនួនព្រឹត្តិការណ៍; Binomial៖ ចំនួនជោគជ័យក្នុង \(n\) ដង។

Part B. Confidence Intervals for the Mean · ចន្លោះទំនុកចិត្តសម្រាប់មធ្យមភាគ

F18z-interval (σ known) · ចន្លោះ z (ស្គាល់ σ)
\(\displaystyle \bar x\pm z_{\alpha/2}\frac{\sigma}{\sqrt n},\qquad E=z_{\alpha/2}\frac{\sigma}{\sqrt n}\ \ (\text{margin of error})\)

Symbols: confidence level \(1-\alpha\); \(z_{\alpha/2}\) = value with area \(\alpha/2\) to its right: 1.645 (90%), 1.960 (95%), 2.576 (99%). Use: σ known, population normal or \(n\) large.

និមិត្តសញ្ញា៖ កម្រិតទំនុកចិត្ត \(1-\alpha\); \(z_{\alpha/2}\) = តម្លៃដែលមានផ្ទៃ \(\alpha/2\) នៅខាងស្តាំ៖ 1.645 (90%), 1.960 (95%), 2.576 (99%)។ ប្រើ៖ ស្គាល់ σ ហើយប្រជាជន normal ឬ \(n\) ធំ។

F19t-interval (σ unknown) · ចន្លោះ t (មិនស្គាល់ σ)
\(\displaystyle \bar x\pm t_{\alpha/2,\,n-1}\frac{s}{\sqrt n},\qquad df=n-1\)

Use: σ unknown (replaced by \(s\)), population approximately normal. The t value is larger than z because \(s\) adds uncertainty; it approaches z as \(n\) grows.

ប្រើ៖ មិនស្គាល់ σ (ជំនួសដោយ \(s\)) ហើយប្រជាជនប្រហែល normal។ តម្លៃ t ធំជាង z ព្រោះ \(s\) បន្ថែមភាពមិនប្រាកដ; វាខិតជិត z ពេល \(n\) ធំ។

F20Sample size for a given margin of error · ទំហំគំរូសម្រាប់ margin of error
\(\displaystyle n=\left(\frac{z_{\alpha/2}\,\sigma}{E}\right)^2\quad\text{(always round up)}\)

Note: \(n\propto1/E^2\): halving \(E\) needs 4 times the sample; doubling \(E\) needs about a quarter.

ចំណាំ៖ បង្គត់ឡើងជានិច្ច។ \(n\propto1/E^2\)៖ បន្ថយ \(E\) ពាក់កណ្តាល ត្រូវការគំរូ 4 ដង។

Exercise 26. Simulation: seeing the properties លំហាត់ 26. ការក្លែងធ្វើ

set.seed(2026)
# (a) bias of the variance (F11)
S2 <- replicate(10000, var(rnorm(5, mean = 50, sd = 10)))
mean(S2)            # about 100 (S^2, divisor n-1)
mean(S2 * 4 / 5)    # about 80  (sigma1^2, divisor n)

# (b), (c) coverage and width of the 95% t-interval (F19)
ci_sim <- function(n, B = 1000) {
  res <- replicate(B, {
    ci <- t.test(rnorm(n, mean = 50, sd = 10), conf.level = 0.95)$conf.int
    c(cover = ci[1] <= 50 & 50 <= ci[2], width = ci[2] - ci[1])
  })
  rowMeans(res)
}
ci_sim(25)     # cover about 0.95, width about 8.2
ci_sim(100)    # cover about 0.95, width about 4.0
(a)The average of \(S^2\) is about 100 \(=\sigma^2\) (unbiased); the average of \(\hat\sigma_1^2\) is about 80 \(=\frac45\sigma^2\), too small by \(\sigma^2/n=20\). This confirms F11.មធ្យមនៃ \(S^2\) ≈ 100 (គ្មានលម្អៀង); មធ្យមនៃ \(\hat\sigma_1^2\) ≈ 80 (តូចពេក 20)។ បញ្ជាក់ F11។
(b)About 95% of the intervals contain \(\mu=50\) (our run: 0.948). This is exactly what “95% confidence” means.ប្រហែល 95% នៃចន្លោះមាន \(\mu=50\) (យើងបាន 0.948)។ នេះជាអត្ថន័យនៃ “95% confidence”។
(c)With \(n=100\) the coverage stays about 0.95, but the average width falls from about 8.2 to about 4.0 (halved), because width \(\propto1/\sqrt n\) and \(\sqrt{100/25}=2\). Exact numbers depend on the seed.ពេល \(n=100\) coverage នៅតែ ≈ 0.95 តែទទឹងមធ្យមថយពី ≈ 8.2 ទៅ ≈ 4.0 (ពាក់កណ្តាល) ព្រោះទទឹង \(\propto1/\sqrt n\)។ លេខពិតអាស្រ័យលើ seed។
