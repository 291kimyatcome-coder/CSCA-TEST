Problem: Let \(A=\{x\in\mathbb{Z}\mid 1\le x<5\}\). The number of subsets of \(A\) is

A. \(32\)B. \(16\)C. \(14\)D. \(15\)

ដំណោះស្រាយ

  1. កំណត់ធាតុនៃសំណុំ \(A\)។ ដោយ \(x\in\mathbb{Z}\) និង \(1\le x<5\) នោះ \(x\) ជាចំនួនគត់ដែលធំជាង ឬស្មើ \(1\) ហើយតូចជាង \(5\) ដាច់ខាត៖ \[x\in\{1,\ 2,\ 3,\ 4\}\] ដូចនេះ \(A=\{1,2,3,4\}\) ហើយចំនួនធាតុនៃ \(A\) គឺ \(n(A)=4\)។
  2. គណនាចំនួនសំណុំរង។ សំណុំដែលមាន \(n\) ធាតុ មានសំណុំរងចំនួន \(2^n\) (ធាតុនីមួយៗ អាចស្ថិតនៅ ឬមិនស្ថិតនៅក្នុងសំណុំរង)។ ដូចនេះ៖ \[\text{ចំនួនសំណុំរងនៃ } A=2^{n(A)}=2^4=16\]
  3. ផ្ទៀងផ្ទាត់។ រាប់តាមចំនួនធាតុក្នុងសំណុំរង៖
    ចំនួនធាតុ01234សរុប
    ចំនួនសំណុំរង\(\binom40=1\)\(\binom41=4\)\(\binom42=6\)\(\binom43=4\)\(\binom44=1\)\(16\)
    (រួមទាំង \(\varnothing\) និង \(A\) ខ្លួនឯង)។

សន្និដ្ឋាន៖ ចំនួនសំណុំរងនៃ \(A\) គឺ \(16\)។   ចម្លើយ៖ B

Solution

  1. Elements of \(A\). Since \(x\in\mathbb{Z}\) and \(1\le x<5\), \(x\) is an integer that is at least \(1\) and strictly less than \(5\): \[x\in\{1,\ 2,\ 3,\ 4\}\] Hence \(A=\{1,2,3,4\}\) and \(n(A)=4\).
  2. Number of subsets. A set with \(n\) elements has \(2^n\) subsets (each element is either in the subset or not). Therefore \[\text{number of subsets of } A=2^{n(A)}=2^4=16\]
  3. Check. Counting by size: \(\binom40+\binom41+\binom42+\binom43+\binom44=1+4+6+4+1=16\), including \(\varnothing\) and \(A\) itself.

Conclusion: \(A\) has \(16\) subsets.   Answer: B
