# របៀបទទួលលទ្ធផលសិស្សចូល Google Sheet

ពេលសិស្សធ្វើវិញ្ញាសារួច ហើយចុច **Submit** លទ្ធផលនឹងចូលទៅក្នុង Google Sheet របស់គ្រូដោយស្វ័យប្រវត្តិ។ សិស្សម្នាក់ធ្វើវិញ្ញាសាមួយ ស្មើនឹងមួយជួរ (row)។

**ព័ត៌មានដែលគ្រូនឹងឃើញ៖**
- ពេលដាក់ស្នើ ឈ្មោះ ថ្នាក់ និងលេខវិញ្ញាសា
- ពិន្ទុ /100 ចំនួនត្រូវ ចំនួនខុស និងចំនួនមិនបានឆ្លើយ
- រយៈពេលដែលបានប្រើ
- លេខសំណួរដែលខុស ឬមិនបានឆ្លើយ
- ពិន្ទុតាមផ្នែកទាំង ៤
- ជួរឈរ Q1 ដល់ Q48៖ **✓** = ត្រូវ, **✗ B** = ខុស (សិស្សជ្រើស B), **–** = មិនបានឆ្លើយ

ការរៀបចំនេះធ្វើតែ **ម្តងគត់** (ប្រហែល ៥ នាទី)។

## ជំហានទី ១ — បង្កើត Google Sheet
1. បើក **https://sheets.new** (ចូលគណនី Google របស់អ្នក)
2. ដាក់ឈ្មោះ Sheet ឧ. **CSCA Results**

## ជំហានទី ២ — បិទភ្ជាប់កូដ
1. នៅក្នុង Sheet ចុចម៉ឺនុយ **Extensions** → **Apps Script**
2. លុបកូដដែលមានស្រាប់ទាំងអស់ (`function myFunction() {}`)
3. ចម្លងកូដទាំងអស់ពីឯកសារ **teacher/Code.gs** ក្នុង GitHub ហើយបិទភ្ជាប់ចូល
4. ចុចរូប 💾 **Save**

## ជំហានទី ៣ — បើកដំណើរការ (Deploy)
1. ចុចប៊ូតុងពណ៌ខៀវ **Deploy** → **New deployment**
2. ចុចរូប ⚙️ ក្បែរ "Select type" ហើយជ្រើស **Web app**
3. កំណត់៖
   - **Execute as:** `Me`
   - **Who has access:** `Anyone`
4. ចុច **Deploy**
5. Google នឹងសុំការអនុញ្ញាត៖ ចុច **Authorize access** → ជ្រើសគណនីរបស់អ្នក → បើឃើញ "Google hasn't verified this app" ចុច **Advanced** → **Go to … (unsafe)** → **Allow**។ នេះជាកូដរបស់អ្នកផ្ទាល់ ដូច្នេះមានសុវត្ថិភាព។
6. ចម្លង **Web app URL** (ចប់ដោយ `/exec`)

## ជំហានទី ៤ — ដាក់ URL ចូលគេហទំព័រ
ផ្ញើ URL នោះមក Claude ឬកែដោយខ្លួនឯង៖
1. នៅក្នុង GitHub បើកឯកសារ **js/config.js** → ចុចរូបខ្មៅដៃ ✏️
2. ដាក់ URL នៅចន្លោះសញ្ញា `''`៖
   ```js
   resultsUrl: 'https://script.google.com/macros/s/……/exec',
   ```
3. ចុច **Commit changes**។ រង់ចាំ ១–២ នាទី ដើម្បីឲ្យ GitHub Pages ធ្វើបច្ចុប្បន្នភាព។

## ពិនិត្យ
បើកគេហទំព័រ ធ្វើវិញ្ញាសាមួយសាក (វាយឈ្មោះ "Test") ហើយចុច Submit។ ពេលឃើញអក្សរ **"✓ Your result was sent to your teacher."** សូមបើក Google Sheet អ្នកនឹងឃើញ Sheet ថ្មីឈ្មោះ **Results** ដែលមានជួរលទ្ធផលនោះ។

## ចំណាំ
- សិស្សត្រូវវាយ **ឈ្មោះ** មុនចាប់ផ្តើមធ្វើវិញ្ញាសា។
- បើអ៊ីនធឺណិតដាច់ពេល Submit គេហទំព័រនឹងបង្ហាញប៊ូតុង **Send again** ឲ្យសិស្សផ្ញើម្តងទៀត។
- ការផ្ញើលទ្ធផលដំណើរការលើតំណ GitHub Pages និងឯកសារ CSCA-Math.html (ពេលមានអ៊ីនធឺណិត)។ វាមិនដំណើរការលើតំណ claude.ai ទេ។
- បើអ្នកកែកូដ Code.gs នៅពេលក្រោយ ត្រូវចុច **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** ដើម្បីឲ្យការកែប្រែមានប្រសិទ្ធភាព (URL នៅដដែល)។
